# Task 1 - Retail Sales Exploratory Data Analysis (EDA)

## Internship

Oasis Infobyte - Data Analytics Internship

## Project Overview

Exploratory Data Analysis of retail sales data using Python, pandas, matplotlib, seaborn and Jupyter Notebook

## Objectives

- Analyze sales trends by month and quarter
- Understand customer demographics by age and gender
- Analyze revenue by product category
- Identify high-value transactions
- Study correlations between numerical variables
- Discover additional business insights

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains 1,000 retail transactions with information about date, customer, gender, age, product category, quantity, price per unit, and total amount.

The dataset contains Product Category but no individual product-name field; therefore, the top 10 highest-value transactions were analyzed as a proxy.

## Key Analysis

- Monthly and quarterly sales trends
- Customer age-group distribution
- Gender distribution
- Revenue by product category
- Top 10 highest-value transactions
- Correlation heatmap
- Quantity vs Total Amount analysis

## Files

- OIBSIP_Retail_Sales_EDA.ipynb
- retail_sales_dataset.csv
- PNG files

## Conclusion

The analysis provides insights into sales trends, customer demographics, category performance, and factors affecting transaction value.

## Business Recommendations

1. Focus marketing and promotions on strong-performing product categories.
2. Use sales trends to plan inventory and promotional campaigns.
3. Use customer demographics to create targeted marketing offers.
